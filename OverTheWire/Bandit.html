OverTheWire - Bandit

Written by: cyberNightKnight

-- Overview --

Bandit is one of OverTheWire's set of challenges that aims to teach Linux CLI commands.

-- Levels --

  1. Level 0 --> 1

    2. Description:

    The goal of this level is for you to log into the game using SSH. The host to which you need to connect is bandit.labs.overthewire.org, on port 2220. The username is bandit0 and the password is bandit0. Once logged in, go to the Level 1 page to find out how to beat Level 1.


    Solution:

    >ssh bandit0@bandit.labs.overthewire.org -p 2220

    >ls

    >cat readme

    Output: {next level's password}

    Explanation:

    This is a secure shell connection through port 2220.

    We view the directory's contents using ls, which contains the readme file. We then visualize the file's content using cat.


  2. Level 1 --> 2

    3. Description:

    The password for the next level is stored in a file called readme located in the home directory. Use this password to log into bandit1 using SSH. Whenever you find a password for a level, use SSH (on port 2220) to log into that level and continue the game.


    Solution:

    >ssh bandit1@bandit.labs.overthewire.org -p 2220

    Note: The password is the one obtained in thte previous level.

    >ls

    Output: -

    Note: Dashes alone are taken as stdin(inputs)/stdout (outputs), so if we want the system to take it as a file, we must add the directory...

    >cat ./-

    Output: {next level's password}

    Explanation:

    We view the directory's contents using ls, which contains the file named with a dash. We visualize the file's content using cat and specifying the current directory.


  3. Level 2 --> 3

    4. Description:

    The password for the next level is stored in a file called --spaces in this filename-- located in the home directory


    Solution:

    >>ssh bandit2@bandit.labs.overthewire.org -p 2220

    >ls

    Output: --spaces in this filename--

    >cat ./"--spacesin this filename--"

    Output: {next level's password}

    Explanation:

    We view the directory's contents using ls, which contains the file with spaces. We visualize the file's content using cat and the file between quotes in the current directory.
