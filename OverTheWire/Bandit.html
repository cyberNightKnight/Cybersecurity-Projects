OverTheWire - Bandit

Written by: cyberNightKnight

-- Overview --

Bandit is one of OverTheWire's set of challenges that aims to teach Linux CLI commands.

-- Levels --

  1. Level 0 --> 1

    2. Description:

    The goal of this level is for you to log into the game using SSH. The host to which you need to connect is bandit.labs.overthewire.org, on port 2220. The username is bandit0 and the password is bandit0. Once logged in, go to the Level 1 page to find out how to beat Level 1.


    Solution:

    >ssh bandit0@bandit.labs.overthewire.org -p 2220

    >ls

    >cat readme

    Output: {next level's password}

    Explanation:

    This is a secure shell connection through port 2220.

    We view the directory's contents using ls, which contains the readme file. We then visualize the file's content using cat.


  2. Level 1 --> 2

    3. Description:

    The password for the next level is stored in a file called readme located in the home directory. Use this password to log into bandit1 using SSH. Whenever you find a password for a level, use SSH (on port 2220) to log into that level and continue the game.


    Solution:

    >ssh bandit1@bandit.labs.overthewire.org -p 2220

    Note: The password is the one obtained in thte previous level.

    >ls

    Output: -

    Note: Dashes alone are taken as stdin(inputs)/stdout (outputs), so if we want the system to take it as a file, we must add the directory...

    >cat ./-

    Output: {next level's password}

    Explanation:

    We view the directory's contents using ls, which contains the file named with a dash. We visualize the file's content using cat and specifying the current directory.


  3. Level 2 --> 3

    >ls

    >cat ./"--spacesin this filename--"

  4. Level 3 --> 4

    5. Description:

    The password for the next level is stored in a hidden file in the inhere directory.


    Solution:

    >>ssh bandit3@bandit.labs.overthewire.org -p 2220

    >ls

    Output: inhere

    Note: It was a different color than the files, so inhere is a directory

    >ls -a

    Output: . .. ...Hiding-From-You

    Note: We use -a to see hidden files. They have "." in front of their name.

    >cat "...Hiding-From-You"

    Output: {next level's password}

    Explanation:

    We visualize the hidden files in the directory using -a, and put the filename between quotes so the system knows we're trying to see the contents of a file.


  5. Level 4 --> 5

    6. Description:

    The password for the next level is stored in the only human-readable file in the inhere directory. Tip: if your terminal is messed up, try the “reset” command.


    Solution:

    >>ssh bandit4@bandit.labs.overthewire.org -p 2220

    >ls

    Output: -file00 -file01 -file02 -file03 -file04 -file05 -file06 -file07 -file08 -file09

    >cat ./-file*

    Note: Displays all the files with "-file" in their name inside current directory.

    Note: Next level's password is in one of the files. Since this was one of my first challenges, I did the search manually, but there are more efficient ways to do this.


  6. Level 5 --> 6

    7. Description:

    The password for the next level is stored in a file somewhere under the inhere directory and has all of the following properties:
    -human-readable
    -1033 bytes in size
    -not executable


    Solution:

    >>ssh bandit5@bandit.labs.overthewire.org -p 2220

    >ls

    Output: maybehere00 maybehere03 maybehere06 maybehere09 maybehere12 maybehere15 maybehere18
    maybehere01 maybehere04 maybehere07 maybehere10 maybehere13 maybehere16 maybehere19
    maybehere02 maybehere05 maybehere08 maybehere11 maybehere14 maybehere17

    Note: All are directories

    >ls -S -R

    Note: Displays all contents of directories.
    -R stands for recursive (displays all elements)
    -S orders files in descending order based on size

    >find . -type f -exec sh -c 'for f do printf "\n%s\n""$f" cat "$f" done' sh {} +

    Note: Finds files in the current directory (type file). Then executes the power shell script: for each file, it will print the directory and its contents. In this case, {}+ is a replacement for the files taken as input for the power shell script.

    Again, I searched manually in each file, but there are more efficient ways of doing this. In the end, the password it was in ./maybehere07/.file2.


  7. Level 6 --> 7

    8. Description:

    The password for the next level is stored in a file somewhere under the inhere directory and has all of the following properties:
    -human-readable
    -1033 bytes in size
    -not executable


    Solution:

    >>ssh bandit6@bandit.labs.overthewire.org -p 2220

    >ls -la

    Output: total 20
    drwxr-xr-x 2 root root 4096 Apr 3 15:17 .
    drwxr-xr-x 150 root root 4096 Apr 3 15:20 ..
    -rw-r--r-- 1 root root 220 Mar 31 2024 .bash_logout
    -rw-r--r-- 1 root root 3851 Apr 3 15:10 .bashrc
    -rw-r--r-- 1 root root 807 Mar 31 2024 .profile

    Note:
    -l →long format (size, permissions, etc.)
    -a →show all files
    -h →convert to human readable format

    >find / -user bandit7 -group bandit6 -type f -size 33c 2>dev/null

    Note: This will output a path.

    >cat {path to directory}

    Output: {password}

    Explanation:

    We find the file path belonging to user bandit7, group bandit6, and of size 1033 bytes. The uses dev/null to hide error messages.


  8. Level 7 --> 8

    9. Description:

    The password for the next level is stored in the file data.txt next to the word millionth


    Solution:

    >>ssh bandit7@bandit.labs.overthewire.org -p 2220

    >grep "millionth" data.txt

    Output: {password}

    Explanation:

    Searches for the word "millionth" in the file data.txt.


  9. Level 8 --> 9

    10. Description:

    The password for the next level is stored in the file data.txt and is the only line of text that occurs only once


    Solution:

    >>ssh bandit8@bandit.labs.overthewire.org -p 2220

    >sort data.txt | uniq -u

    Output: {password}

    Explanation:

    Sorts/organizes the file's content in alphabetical order and then searches for the ones that do not repear.


  10. Level 9 --> 10

    11. Description:

    The password for the next level is stored in the file data.txt in one of the few human-readable strings, preceded by several ‘=’ characters.


    Solution:

    >>ssh bandit9@bandit.labs.overthewire.org -p 2220

    >strings data.txt | grep -P -a '=+.+'

    Note: Strings removes all binary ‘garbage’ and leaves only human-readable text
    -P returns the entire line
    -a outputs the text
    This regex is saying to look for any 1 or more character (.+) preceded by one or more ‘=’ (=+)

    Output: {password}


  11. Level 10 --> 11

    12. Description:

    The password for the next level is stored in the file data.txt, which contains base64 encoded data


    Solution:

    >>ssh bandit10@bandit.labs.overthewire.org -p 2220

    >base64 -d data.txt

    Output: {password}

    Explanation:

    Decodes data stored in the file.


  12. Level 11 --> 12

    13. Description:

    The password for the next level is stored in the file data.txt, where all lowercase (a-z) and uppercase (A-Z) letters have been rotated by 13 positions


    Solution:

    >>ssh bandit11@bandit.labs.overthewire.org -p 2220

    >cat data.txt | tr 'a-zA-Z' 'n-za-mN-ZA-M'

    Output: {password}

    Explanation:

    This is a ROT 13 (letters were rotated 13 times over; it's a cipher). M is the 13th letter, so it will be the equivalent of A.

    In this case, tr does the rotation. The ranges are lower and uppercase a-z.
    The second string contains the rotated numbers starting from the thirteenth letter (M), which will be the equivalent of 'A'.


  13. Level 12 --> 13

    14. Description:

    The password for the next level is stored in the file data.txt, which is a hexdump of a file that has been repeatedly compressed. For this level it may be useful to create a directory under /tmp in which you can work. Use mkdir with a hard to guess directory name. Or better, use the command “mktemp -d”. Then copy the datafile using cp, and rename it using mv (read the manpages!)


    Solution:

    >>ssh bandit12@bandit.labs.overthewire.org -p 2220

    >mkdir /tmp/bandlvl12

    or

    >mktemp -d /tmp/bandlvl12.XXX
